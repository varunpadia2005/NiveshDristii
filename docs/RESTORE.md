# RESTORE.md (NEW, F8) — rebuilding everything on a NEW machine

Prerequisites: git, Python 3.13 (3.11+ per pyproject), pip, internet ONCE
for pip only. No other network use. Never touch the default fund directory
(`~/niveshdristi/funds`) during tests.

## 1. Clone and install

```
git clone https://github.com/varunpadia2005/NiveshDristii.git
cd NiveshDristii
git checkout rebuild/v2
py -3.13 -m venv "D:\venvs\niveshdristi"
"D:\venvs\niveshdristi\Scripts\pip" install -e ".[dev]"
```

The venv MUST live OUTSIDE the repo tree: G02 (stray-file scan) and G18
(zero-write) sweep the whole repository and would trip over site-packages.

## 2. Legacy fixtures (F2 situation)

Five legacy characterization tests read `tests/fixtures/prices_reliance
_30d.parquet`, which is GITIGNORED (blanket `*.parquet` since 82f76d8) and
generated by the legacy `tests/create_fixtures.py` (never committed). After
cloning, run ONCE:

```
.venv\Scripts\python tests\create_fixtures.py
```

Without it, `tests/test_characterization.py` fails with FileNotFoundError
(5 tests). The output parquets (`indicators_output`, `backtest_equity_curve`,
`backtest_trades`) are written by the tests themselves and compared
byte-identical by G18.

## 3. The phase0 worktree (for gate G04/G05) — WITHOUT touching the repo

The gate compares the LEGACY tree against a frozen phase0 snapshot
(commit 82f76d8). Create it as a WORKTREE, not a second clone of your repo:

```
git worktree add "D:\Nivesh Dristi\phase0_wt" 82f76d8
copy tools\dump_config.py      "D:\Nivesh Dristi\phase0_wt\tools\"
copy tools\compare_backtest.py "D:\Nivesh Dristi\phase0_wt\tools\"
```

The two tool copies in the phase0 tree are the FROZEN comparators; G03b
hashes them (LF-normalized since F8) before G04/G05 run. G05's comparator
also READS tests/fixtures/prices_reliance_30d.parquet from the phase0
tree, so copy the fixture you generated in step 2 into it:

```
copy tests\fixtures\prices_reliance_30d.parquet "D:\Nivesh Dristi\phase0_wt\tests\fixtures\"
```

## 4. Run the gate TWICE

```
.venv\Scripts\python tools\phase1_gate.py --phase0 "D:\Nivesh Dristi\phase0_wt"
```

Run 1 may FAIL G18 (the legacy tests rewrite the gitignored fixture parquets
byte-identically; the first run establishes them). Run 2 must be
`GATE: PASS`. If run 2 still fails, stop and compare outputs — do not edit
legacy files.

## 5. Backups

`D:\Nivesh Dristi\niveshdristi-rebuild-v2.bundle` (+ dated copies) holds the
full `rebuild/v2` history; `repo_snapshot_*.txt` records HEAD, branches and
the environment. Restore from a bundle with
`git clone niveshdristi-rebuild-v2.bundle restored && cd restored && git checkout rebuild/v2`.

## 5. Paper-fund backup / restore (operator procedure)

The fund directory `<base>/<fund-id>/` is self-contained:
`ledger.jsonl` (truth), `broker_cache.json` (derivable),
`decisions/` (R9b sidecars, derivable display artifacts),
`snapshots/` (the as-of frames replay needs),
`events.jsonl` + `heartbeat.json` (observability), `halt.flag` (state).

**Backup**: stop ticking (or accept a torn tail), then copy the WHOLE
directory. Restore: copy back and run `nd paper verify <fund-id>` — it
must print verified; then `nd paper replay` must be byte-identical for
every session whose snapshots exist.

**Do NOT** hand-edit the ledger: a one-byte change fails verification
(by design; see the tamper tests). A damaged fund is never auto-repaired —
`nd paper recover` rebuilds the DERIVABLE cache from the ledger only.
