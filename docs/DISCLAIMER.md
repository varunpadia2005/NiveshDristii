## Regulatory Context (India)

Under SEBI regulations:
- **Research Analyst Regulations (2014)**: Giving investment recommendations for a fee requires registration
- **Investment Adviser Regulations (2013)**: Providing investment advice requires registration
- **Algorithmic Trading**: Retail algo trading via broker APIs has evolving SEBI/exchange frameworks

**Keep NiveshDristi as a personal/educational tool. Show this disclaimer on every screen and report. Do not distribute outputs as recommendations without checking current SEBI rules.**
